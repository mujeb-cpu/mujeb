# Future work

The following are intentionally outside this frontend MVP:

- Refund execution, shipping labels, exchanges, store credit, warranty, and warehouse routing
- WhatsApp, notifications, customer-support inboxes, and autonomous agents
- Fraud scoring, advanced analytics, billing, subscriptions, and enterprise permissions
- Multi-platform, multi-store, and full team administration
- Arabic localization and RTL implementation
- Live Salla/Zid OAuth and production commerce adapters

Before a real pilot, implement server-side authentication and authorization, merchant isolation, customer order scope, protected token storage, rate limiting, observability, monitoring, backups, and security testing.
